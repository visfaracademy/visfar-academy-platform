## 7. Những điểm tốt cần giữ nguyên khi xây mới

(Trích từ báo cáo; đã đối chiếu lại bằng grep trong phiên audit.)

- **Không trùng `id`:** 72 id, 0 trùng — hiếm gặp ở file qua nhiều lần sửa.
- **Không có XSS sink trực tiếp:** `innerHTML` = 0, `outerHTML` = 0, `document.write` = 0, `eval(` = 0, `insertAdjacentHTML` = 0 (theo báo cáo); dữ liệu người dùng chèn bằng `textContent`/`createTextNode`.
- **Link ngoài an toàn:** 8 link `target="_blank"` đều có `rel="noopener"` (theo báo cáo); chỉ có 2 domain ngoài: `zalo.me` và `script.google.com`.
- **Accessibility nền tốt:** `lang="vi"`, 99 `aria-*`, 19 `role=`, `aria-labelledby` trên 12/13 section, `aria-label` cho từng vòng SVG, `prefers-reduced-motion` ×15 (theo báo cáo). Điểm thiếu: không có skip-link, không có `<h1>` chính, iframe `#sheetFrame` có `title=""` rỗng (dòng 4437).
- **Design system tái dùng được:** CSS variables `--gold`, `--gold2`, `--grad`, `--ink`, khung `.wrap{max-width:1380px}`, gradient vàng chéo 135° (`#6e4f0a → #a67c00 → #c9a227 → #d4af37 → #e8c766 → #8c6d1f`, điểm sáng nhất chỉ ở góc chéo 90%, không còn điểm trắng `#fff6c8` giữa chữ — grep = 0 theo báo cáo), Be Vietnam Pro, hover chuẩn toàn trang (nâng `translateY(-3px)`, 220 ms).
- **Trust assets:** 8 testimonial có tên/chức danh/ảnh (user đã xác nhận cho phép đăng), 4 trang chính sách có toàn văn — tái dùng, nhưng cần versioning + ngày cập nhật.
